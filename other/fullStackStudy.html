    # Week 7-10: Express.js (轻量优先)

    // 项目结构

├── app.ts           // 入口

- 请求验证 (Zod / Joi)
- 文件上传 (Multer)
- Session / JWT 认证
- Rate Limiting 限流
- CORS 安全配置

    # 第三阶段：全栈整合 (8-10周)

    # Week 15-18: Next.js App Router 深度

    // 目录结构 (App Router)
app/
├── (auth)/              // 路由组
│   ├── login/
│   └── register/
├── (dashboard)/
│   ├── layout.tsx       // 共享布局
│   ├── page.tsx         // 页面
│   └── settings/
│       └── page.tsx
├── api/                 // API Routes
│   ├── auth/[...nextauth]/
│   └── trpc/[...trpc]/
├── layout.tsx           // 根布局
└── page.tsx             // 首页

// 核心概念
- Server Components vs Client Components
- Server Actions (表单处理)
- Route Handlers (API)
- Middleware (请求拦截)
- Streaming & Suspense
- Server/Client 数据获取模式

    # 第四阶段：工程化 (6-8周)

    # Week 25-26: Docker 容器化

    # Dockerfile 多阶段构建
FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN npm ci

FROM node:20-alpine AS builder
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

FROM node:20-alpine AS runner
COPY --from=builder /app/.next ./.next
EXPOSE 3000
CMD ["npm", "start"]

    # 学习检查清单

    # 第一阶段检查点

    • [ ] 能熟练使用泛型和高级类型
    • [ ] 理解 Node.js 事件循环机制
    • [ ] 能编写基础 SQL 查询和设计表结构
    • [ ] 了解 Redis 基本数据类型

    # 第二阶段检查点

    • [ ] 能独立搭建 Express/NestJS 项目
    • [ ] 理解 RESTful API 设计规范
    • [ ] 能实现 JWT 认证和权限控制
    • [ ] 熟练使用 Prisma 进行数据操作

    # 第三阶段检查点

    • [ ] 掌握 Next.js App Router 核心概念
    • [ ] 能区分 Server/Client Components 使用场景
    • [ ] 能实现完整的认证流程
    • [ ] 掌握 React Query 数据缓存策略

    # 第四阶段检查点

    • [ ] 能编写 Dockerfile 和 docker-compose
    • [ ] 能编写单元测试和 E2E 测试
    • [ ] 能配置 GitHub Actions CI/CD
    • [ ] 能将应用部署到生产环境
