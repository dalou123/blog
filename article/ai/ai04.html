    Claude Code 使用指南(一)

    dalou 2026/1/20 AI开发工具

    # 什么是 Claude Code？

    Claude Code 是 Anthropic 官方推出的 CLI（命令行界面）工具，让开发者能够直接在终端中与 Claude AI 助手进行交互。它不同于网页版的聊天界面，而是专为开发者设计的工作环境，能够直接操作文件系统、执行命令、运行测试。

    简单来说，Claude Code 就是把 Claude 搬到了终端里，你可以把它想象成一个拥有 AI 能力的超级终端助手：

    • 能读取和编辑你的代码文件
    • 能运行 bash 命令和脚本
    • 能使用 Git 进行版本控制
    • 能安装和使用各种插件和技能
    • 能在后台运行任务

    # Claude Code 安装与配置

    # 1、安装 Claude Code

    Claude Code 支持多种安装方式，最简单的是使用官方安装脚本：

    curl -fsSL https://claude.ai/install.sh | sh

    Windows 安装

    npm install -g @anthropic/claude-code
#验证安装
claude –version

    Linux/ macOS 安装

    # 全局安装 Claude Code
sudo npm install -g @anthropic/claude-code
# 验证安装
claude --version

    2
    3

    安装完成后，你可以在终端中直接使用 claude 命令启动：

    claude
    1

    首次启动时，系统会引导你完成登录配置，绑定你的 Anthropic 账户。

    # 2、基本命令

    进入 Claude Code 后，你可以使用以下命令：

    • /help - 查看帮助信息
    • /exit 或 /quit - 退出 Claude Code
    • /clear - 清空对话历史
    • /settings - 打开设置面板

    # 安装CC-Switch

    CC-Switch 本质上就是一个 终端智能体的配置文件管理工具。

    # 核心功能与价值

    • ‌统一配置管理‌：cc-switch 的核心功能是‌集中管理 Claude Code 等工具的连接配置（如 base_url、api_key）‌，允许用户创建并保存多个预设配置（profile），实现一键切换。‌‌
    • ‌无缝模型切换‌：它解决了用户同时使用多个 AI 编程模型（如 Claude、GLM、Kimi）时，需要反复重启或手动更改配置的痛点，‌像切换电视频道一样在不同模型间快速切换‌。‌‌
    • ‌扩展能力集成‌：除了管理基础连接，cc-switch 还致力于‌统一管理 Skills（技能）、Prompts（提示词）以及 MCP（Model Context Protocol）配置‌，避免用户在不同工具间重复进行相同的设置操作。‌‌
    • ‌环境状态可视化‌：该工具包含‌环境变量检测模块‌，可以图形化地展示和排查多 CLI 环境下可能存在的环境变量冲突，辅助用户诊断问题。‌‌

    # 安装方式

    Windows 用户 从 Releases 页面下载最新版本的 CC-Switch-v{版本号}-Windows.msi 安装包或者 CC-Switch-v{版本号}-Windows-Portable.zip 绿色版。

    macOS 用户 方式一：通过 Homebrew 安装（推荐）

    brew tap farion1231/ccswitch

brew install --cask cc-switch

    # Claude Code 核心功能

    # 1、智能代码操作

    Claude Code 最强大的功能是能够直接操作你的代码文件。你可以像平常聊天一样与它对话：

    用户：帮我分析 src/components/Button.tsx 这个组件的结构
    1

    Claude 会自动读取该文件，并给出详细的分析，包括组件功能、代码结构、潜在问题等。

    # 2、Git 集成

    Claude Code 深度集成了 Git 功能，你可以让它帮你进行版本控制操作：

    用户：查看当前的 git 状态
    1

    它会执行 git status 并展示结果。

    用户：帮我创建一个提交，消息是"修复登录页面的样式问题"
    1

    它会自动：

    1. 查看 git 状态
    2. 查看修改内容
    3. 查看最近的提交历史以保持风格一致
    4. 执行 git add 和 git commit

    # 3、任务管理

    对于复杂的任务，Claude Code 会自动创建任务列表来跟踪进度：

    用户：帮我重构这个项目，把所有的 setTimeout 替换为 Promise
    1

    它会创建待办事项列表，逐一处理文件，完成后标记为已完成，让你清楚地看到进度。

    # 4、后台任务

    某些耗时操作可以在后台运行，不会阻塞你的其他操作：

    claude run-in-background "运行完整的测试套件"
    1

    你可以在执行其他任务的同时，让测试在后台运行，随时查看结果。

    # 插件和技能系统

    Claude Code 拥有强大的插件系统，可以扩展其功能。

    # 1、安装插件

    /plugin marketplace add anthropics/skills
    1

    # 2、安装技能包

    /plugin install example-skills@anthropic-agent-skills
    1

    安装后，Claude 会自动检测你安装的技能，并在合适的时机询问是否使用。

    # 最佳实践

    # 1、提供清晰的上下文

    当你需要 Claude Code 帮助处理代码时，尽量提供清晰的上下文：

    好：把 Header 组件的背景色从蓝色改成绿色，保持当前的所有其他样式不变

不好：改一下 Header 的颜色
    1
    2
    3

    # 2、使用文件路径

    直接指定文件路径，让 Claude Code 精确定位：

    好：修复 src/api/user.ts 中的登录接口错误

不好：修复那个登录接口的问题
    1
    2
    3

    # 3、分步执行复杂任务

    对于复杂的重构或大型功能，让 Claude Code 分步执行，你可以每一步都进行审查：

    用户：逐步迁移这个项目到 TypeScript，每次处理一个文件，等我说继续后再处理下一个
    1

    # 4、善用任务列表

    当 Claude Code 自动创建任务列表时，你可以：

    用户：跳过第 3 个任务，继续做其他的
    1

    或者手动添加任务：

    用户：添加一个任务：写测试代码
    1

    # 高级技巧

    # 1、使用 Plan Mode

    对于需要规划的任务，可以使用 Plan Mode，让 Claude Code 先分析代码库，制定详细的实现计划：

    用户：进入 Plan Mode，帮我规划如何在这个项目中添加深色模式功能
    1

    # 2、自定义配置

    通过 .clauderc 配置文件，你可以自定义 Claude Code 的行为，比如默认的工作目录、忽略的文件等。

    # 3、结合 MCP 使用

    Claude Code 支持 MCP（Model Context Protocol），可以连接外部工具和数据源，增强 Claude 的能力：

    /plugin install my-mcp-server
    1

    # 常见问题

    Q：Claude Code 会修改我的代码吗？ A：Claude Code 只在你明确请求时才会修改代码，并且每次修改前都会先读取文件内容。你可以随时撤销它的更改。

    Q：Claude Code 能运行任何命令吗？ A：可以，但建议让 Claude Code 通过对话来执行命令，这样你可以看到它在做什么。

    Q：如何查看后台任务的进度？ A：使用 /tasks 命令可以查看所有任务及其状态。

    Q：Claude Code 会发送我的代码到云端吗？ A：是的，为了获得 AI 能力，代码会被发送到 Anthropic 的服务器。请确保遵守你所在组织的安全政策。

    # 总结

    Claude Code 是一个强大的 AI 驱动开发工具，它将 AI 的智能与终端的效率完美结合。通过熟练使用 Claude Code，你可以：

    • 更快地理解和修改代码
    • 自动化重复性的开发任务
    • 获得实时的代码审查和建议
    • 让 AI 协助你完成复杂的重构和功能开发

    开始使用 Claude Code，让 AI 成为你的日常编程伙伴吧！
